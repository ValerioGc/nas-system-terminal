# Changelog

## [0.9.1]

### Fixed

- The pty of the shell is registered with `AsyncFd::register`, which tokio 1.53.3 asks for in place
  of the deprecated `AsyncFd::new`.
- The icons keep their size in the production build. `CommonIcon` built its size class at runtime,
  so PurgeCSS removed `common_icon_small` and `common_icon_medium` and the icons had no width.

### Changed

- The Rust tests moved from `backend/tests/` into the package they test (`backend/axum/tests/`),
  which has `autotests = false`: rust-analyzer loads only the files of the package and reported the
  test modules as unresolved (E0583), although they built and passed.
- Development dependencies updated as Dependabot proposed (Vite 8.3.4, Vitest 5.0.4, Playwright 1.64,
  ESLint 10.12, Prettier 3.9.10, postcss-combine-duplicated-selectors 11 and the others), TypeScript
  kept at 6.0.3; in the pipelines actions/setup-node 7.1.0, upload-artifact 7.0.2 and
  download-artifact 8.0.2; serde_json 1.0.154, tokio 1.53.3 and hyper 1.12.0.
- Unused code removed. The `error` prop of `CommonField`, the `saved` and `changed` props and the
  slot of `CommonSaveFooter`, the boolean returned by `saveSettings`, the `useI18n` export, the
  `@tests` alias and the PurgeCSS safelist patterns that matched no class are gone.
- The tokio `sync` and `time` features, used only by the tests, moved to `dev-dependencies`.
- Code comments shortened, with a `SAFETY` note on every `unsafe` block.

## [0.9.0]

- Initial release of the NAS system terminal as an external application.
